YouTube Reader

YouTube Reader is a private tool that runs on one person's own computer. It is not offered to anyone else.

Privacy policy

With read-only permission (youtube.readonly), it reads the signed-in owner's own YouTube lists: liked videos, playlists, subscriptions and comments on their channel. It cannot change anything on YouTube.

What it reads stays on that computer. It is not sold, shared, sent to any server run by this tool, or used for advertising. The sign-in token is kept in the computer's Keychain.

Access can be removed at any time at myaccount.google.com/permissions.

Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
